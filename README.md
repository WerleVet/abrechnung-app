# Abrechnung

Erfassung von Reisezeit, Arbeitszeit und Belegen am Handy.

Die App speichert alles ausschliesslich im Browser des Geraets. Sie hat kein
Backend, ruft keine fremden Dienste auf und greift nicht auf den Standort zu.

Erzeugt aus dem Ordner `app/` eines privaten Repositories. Nicht von Hand
bearbeiten, Aenderungen gehen dort hinein.
